# Smart Hospital Management & Resource Allocation System

A C-language based hospital management system developed for efficient patient registration, triage queue management, ward bed allocation, and automated billing calculation.

## Features
- **Patient Intake & Registration**: Supports parallel array record management.
- **Billing & Discount Engine**: Automatic 15% discount for Seniors (>=60) and 10% for Children (<=12).
- **Emergency Triage Priority**: Categorizes patients by urgency levels (Critical, Urgent, Normal).
- **Ward Bed Allocation Engine**: Dynamic allocation for General, Paediatric, Surgical, and ICU wards.
- **Analytics & Status Overview**: Displays system-wide patient statistics and waiting times.

## System Requirements
- GCC Compiler / Code::Blocks IDE
- Language: C (C99 standard or higher)
